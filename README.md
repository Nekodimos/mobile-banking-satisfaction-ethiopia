# Impact of Mobile Banking Payment Usability and Speed on Customer Satisfaction in Ethiopia

## Project Description
This research project investigates how mobile banking payment usability and transaction speed affect customer satisfaction in Ethiopia, focusing on three major platforms: **telebirr**, **Commercial Bank of Ethiopia (CBE)**.
